# Lemonade: 12 Days of Summer

**[PLAY IN BROWSER — V0.15.0](https://aidan600.github.io/lemonade-15-days-of-summer/)**

Choose what to sell, set prices and compete against Sally over twelve days.
V0.15.0 adds the approved handmade street, 15 customer drawings, distinct
YOU/Sally stands and faithful keepers, five neighborhood illustrations, simple
weather, real sample cups, flavor-choice icons and sold/made panels. Windows
and Web share a 60 FPS cap. Economics and replay clocks match V0.14.9.
The six-item shop, returning Regulars and reliable forecasts remain; both shop
breaks occur before Days 5 and 9. Built with Godot 4.7.2 stable, Compatibility.
