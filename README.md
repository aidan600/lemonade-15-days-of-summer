# Lemonade: 12 Days of Summer

**[PLAY IN BROWSER — V0.15.3](https://aidan600.github.io/lemonade-15-days-of-summer/)**

Choose what to sell, set prices and compete against Sally over twelve days.
V0.15.3 adds the approved How to Compete introduction before a new summer.
Continue reads it for this session; Don't Show Again saves the optional preference.
The small landing-page link always opens it for manual reading. Existing tutorial
preferences remain separate. A surrounding click buffer makes SLOW / PLAY / FAST
and the gaps between them safe to click during street playback.

Economic simulation, Sally, customer random streams, weather, artwork, Summer
Records and replay timing retain V0.15.2 behavior. Godot 4.7.2 stable,
Compatibility renderer, existing 60 FPS ceiling and VSync.
