# Lemonade: 12 Days of Summer

**[PLAY IN BROWSER — V0.14.9](https://aidan600.github.io/lemonade-15-days-of-summer/)**

Choose what to sell, set prices and compete against Sally over twelve days.
V0.14.9 includes 19 approved hand-drawn illustrations and Lemonade Street,
fast Sally shop planning with bounded sibling/menu refinement, the six-item
shop and returning Regulars, and reliable forecasts. Both shop breaks occur
before Days 5 and 9. Built with Godot 4.7.2 stable, Compatibility renderer.
