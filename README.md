# Lemonade: 12 Days of Summer

**[PLAY IN BROWSER — V0.15.1](https://aidan600.github.io/lemonade-15-days-of-summer/)**

Choose what to sell, set prices and compete against Sally over twelve days.
V0.15.1 opens on the approved landing page with the Lemonade wordmark, two
small decorative street stands, five Summer Records and the yellow Play action.
Play retains Sally selection, the Summer Goal introduction, neighborhood briefing
and Day 1 guide. Confirmed New Game and completed NEW SUMMER return to records.
Windows records persist locally; Web records reset on reload. Economics, Sally,
random streams and street replay remain unchanged from V0.15.0.
Built with Godot 4.7.2 stable, Compatibility renderer, with the existing 60 FPS cap.
