# Lemonade: 15 Days of Summer

A small competitive lemonade-stand game.

Compete against Sally over a 15-day summer: choose what to sell, set prices,
build neighborhood Buzz, and save toward a summer goal.

## Download

[Download the latest Windows build from Releases.](https://github.com/aidan600/lemonade-15-days-of-summer/releases/latest)

Extract the ZIP and double-click **Lemonade.exe**.

No Godot installation is required.

This is currently an unsigned playtest build, so Windows may show an
unfamiliar-app / SmartScreen warning.
